      在线演示版
      
    本页是在线静态演示：没有本机 Node 后端，壁纸库列表 / 属性保存 / 删除 / 打开所在文件夹 / 渲染器诊断流（/api/* 与 /diag）在线上全部不可用 —— 这不是故障，是纯静态托管的必然结果。「选择文件夹」纯前端扫描仍然可用，默认载入的是本仓库自造的合成样例（不含任何真实壁纸）。
    
      
    默认壁纸：合成样例 scene.pkg（由 make-sample.mjs 生成，33 299 B，无第三方内容）—— 本仓库不分发任何真实壁纸包。
    
      
    Online demo — this page is an online static demo: there is no local Node backend, so the library listing, property saving, deleting, reveal-in-folder and the renderer diagnostics stream (/api/*, /diag) are unavailable online (by design, not a failure). “Choose folder” still works, and the default wallpaper is this repository's own synthetic sample — no real wallpaper is bundled or redistributed.
